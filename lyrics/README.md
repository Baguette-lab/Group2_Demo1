# Our selected lyric passages

These files contain the 13 passages supplied in the group’s draft, with line timestamps matched to the supplied MP3 recordings. They are excerpts, rather than full-song lyrics. Four files remain empty because those songs have no group-selected passage yet: Hallelujah, Bye Bye Bye, and both Paalam songs.

The presentation uses `presentation-data.js` for its preset cues and line boundaries; these LRC files retain the same lines and timestamps in a readable sidecar format. Updating a sidecar alone does not change the app’s cues. Keep both files consistent when making future shared revisions.

The corrected player uses prepared WAV files in cuts/ with clip-relative line timings. It does not apply old browser rehearsal trims. Updating a source-recording cue requires updating its prepared cut and clip-relative timings together.
